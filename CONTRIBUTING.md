# Contributing to Java Starting from 0

Thanks for your interest in contributing! This repository exists to help people learn Java, and every contribution helps make it better.

## How to Contribute

### Reporting Issues

If you find a bug, typo, or unclear explanation:

1. Open a [GitHub Issue](https://github.com/gitguild/JAVA-Starting-from-0/issues/new).
2. Clearly describe the problem — which file, what line, and what the issue is.
3. Suggest a fix if you have one in mind.

### Suggesting Improvements

Have an idea for a new topic, exercise, or better explanation? Open an issue with the **enhancement** label and describe your suggestion.

### Submitting Code

1. **Fork** the repository.
2. **Create a branch** for your change:
   ```
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes.** Follow the style and conventions of existing code.
4. **Test your code.** Make sure it compiles and runs correctly.
5. **Commit** with a clear message:
   ```
   git commit -m "Add: example for switch-case statements"
   ```
6. **Push** your branch and open a **Pull Request**.

## Code Guidelines

- Keep examples **beginner-friendly** — explain what the code does in comments.
- Use **meaningful variable names**.
- Each file should focus on **one concept**.
- Use `System.out.println()` for output — keep it simple.
- Add a brief comment at the top of each file describing what it demonstrates.

## File Structure

```
TopicName/
  ├── ConceptName.java
  ├── ConceptNameExample.java
  └── README.md          (optional, for additional explanation)
```

## Pull Request Checklist

- [ ] Code compiles without errors
- [ ] Code runs and produces expected output
- [ ] Comments explain the logic clearly
- [ ] File naming follows the existing convention
- [ ] PR description explains what was added or changed

## Code of Conduct

By contributing, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions?

Open an issue with the **question** label if anything is unclear. No question is too small — this repo is for learners.

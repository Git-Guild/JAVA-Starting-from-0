# ☕ Java Starting from 0

> A comprehensive, beginner-friendly repository for learning the Java programming language from absolute scratch.

## 🚀 About This Repository

This repository is designed for **absolute beginners** who want to learn Java from the ground up. Whether you have never written a line of code or are transitioning from another language, this resource provides a structured, step-by-step path to mastering Java fundamentals.

Each topic includes clear explanations, code examples, and practice exercises to reinforce learning.

## 📚 Topics Covered

This repository is organized into progressive learning modules:

* **Core Syntax:** Variables, Data Types, Operators, and basic Control Flow (if/else, loops).
* **Methods:** Defining functions, parameters, and return values.
* **Arrays:** Working with single and multi-dimensional arrays.
* **OOP Basics:** Classes, Objects, Constructors, and Encapsulation.
* **Advanced OOP:** Inheritance, Polymorphism, Interfaces, and Abstract Classes.
* **Java Collections:** Exploring Lists, Sets, and Maps.
* **Exception Handling** and File I/O.
* **Practice Projects:** Small, hands-on applications to apply learned concepts.

## 🛠️ Environment Setup

To follow along with this repository, set up your development environment as follows:

* **Language:** Java SE (Standard Edition)
* **JDK:** **OpenJDK 25.0.1** (or the latest stable version)
* **IDE:** **VS Code** (with the Java Extension Pack recommended)

### Quick Start

1. Install the latest JDK from [Adoptium](https://adoptium.net/) or your preferred distribution.
2. Install [Visual Studio Code](https://code.visualstudio.com/).
3. Install the **Extension Pack for Java** in VS Code.
4. Clone this repository and open the folders in VS Code to explore each topic.

---

## 📂 How to Use This Repository

1. **Start from the beginning** — Topics are ordered from basic to advanced.
2. **Read the comments** — Each code file includes inline comments explaining the logic.
3. **Run the code** — Execute examples locally to see how they work.
4. **Modify and experiment** — Change values, add logic, and break things to learn.
5. **Complete the exercises** — Practice files are included for self-assessment.
